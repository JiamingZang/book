### 市场微观结构（1.6 / 8.11）

| 术语 | 全称/含义 |
| --- | --- |
| Ask / Bid | 卖价/买价；你买入成交在 Ask、卖出成交在 Bid，一进一出天然亏一个点差（1.6） |
| 点差 | Spread；Ask − Bid，进出一次的固定成本；流动性越厚越窄，亚盘/数据瞬间放大数倍（1.6） |
| 滑点 | Slippage；价格跳空时市价单/止损单以更差价格成交（价位没人接单）；限价单不会滑点（1.6） |
| 插针 | Spike；流动性瞬间枯竭时价格冲出极端影线又立刻收回；不全是机构扫止损（1.6 / 5.3） |

| Gap | 缺口/跳空；价格瞬间跳过价位形成的空档——突破/测量/衰竭缺口语义不同（EG/BOG/MG） |

### 风险与计量

| 术语 | 含义 |
| --- | --- |
| R | 风险单位，1R=单笔止损金额 |
| RR | Risk-Reward，风险回报比 |
| ATR | Average True Range，平均真实波幅 |
| Pip | 点，外汇最小报价单位（通常 0.0001） |
| 期望值 | 胜率×平均盈利 − 败率×平均亏损 |
| 凯利公式 | Kelly Criterion；f*=(b×p−q)/b，仓位的“理论上限”不是目标——输入不准+回撤极深，实践用 f/2~f/4（6.7） |
| 破产概率 | Risk of Ruin；账户跌到爆仓线的概率；0.5% 风险 + 10% 回撤线 = 20 次犯错预算，风险减半存活率数量级提升（6.8） |
| 复利 | Compounding；权益增长后同样风险百分比对应更大绝对金额，仓位自动变大；别手动加风险（6.9） |
| 夏普比率 | Sharpe Ratio；（收益−无风险利率） ÷ 波动；衡量每单位波动换来的超额收益，简化版看平均收益/回撤（8.9） |
| 过拟合 | Overfitting；参数调太细只拟合历史噪声，样本外即失效；用样本外数据 + 参数敏感性检验（8.2） |
| 一致性规则 | Consistency Rule；部分平台要求单笔盈利不超过总盈利的某比例，防重仓赌一把；考核失败常见原因之一（9.4） |
| 执行率 | 完全符合计划的交易占比 |
| SQN | 系统质量指数，√N × 平均R ÷ R标准差（>2 才算有优势） |
| Z 分数 | 衡量盈利是否显著偏离随机（2-5 为盈利交易者常见区间） |
| PDT | Pattern Day Trader，日内交易者规则；美股账户 <$25,000 时每 5 个交易日最多 3 次日内交易（超限冻结） |

## C. 网络大 V 系统参考

怎么看待和利用网上交易大 V 公开的系统。先立态度——**大 V 是用来“取材”的，不是用来“信”的**。他们的系统本质都不超出本书框架，价值在具体的执行细节，陷阱在营销话术。

### C.1 先立态度：大 V 系统的真相

看任何大 V 系统前，记住三条：

1. **“80% 胜率”“日赚 1000 刀”是营销话术。** 真实可持续的胜率配合 RR2，长期期望值就已经很好了。宣称超高胜率/暴利的，要么选择性展示，要么在卖课。
2. **大 V 的系统本质都是本书框架的变体。** 剥开术语，都是“结构+位置+确认+风险管理”。他们提供的是具体执行细节（什么品种、什么时段、什么 setup），不是新真理。
3. **免费内容是引流，核心往往在付费。** 公开视频学方法思路可以，别指望免费部分给你完整可盈利系统。

正确的用法：从大 V 那里取材（品种选择、时段、具体 setup 的呈现方式），用本书的框架（验证、仓位、风控）去筛选和落地。不照搬，不迷信。

- **交易什么**：E-mini 5 分钟日内。
- **核心方法一（微通道，第 4.6 已融入）**：3 根同向 K 线 + 微小缺口定义微通道，基础胜率 70%；10 项强度指标每缺 1 项扣 5%；iStop/aStop 双止损体系；以实际风险 aRisk 的 2 倍为目标；超过 6-7 根 K 线警惕回撤。
- **核心方法二（突破白皮书，第 3.11 已融入）**：突破后续 K 线（FT）概率 48%；第一波成立后第二波 > 90%；MIG 97%；四个筛选器（避第 3 信号/避通道 3-4 波段/控时段/控回调深度）把 SQN 从 6.3 提到 8.9。
- **有用的**：“设计致胜”的系统开发理念；把“信号 K 质量”等主观概念量化成 IBS、CX 因子这类可编程指标——这是从“感觉”到“规则”的最佳示范；用 SQN 做优化前后对比（第 8.9）。
- **要警惕的**：微通道本质是刮头皮/快节奏交易，新手执行不了；量化结论基于 E-mini 特定时段，跨品种需重新验证。

### C.8 GRANDMA——“连奶奶都会交易”的故障安全入场（Rose）

- **是谁**：Rose，中文圈价格行为交易者，公开策略 GRANDMA（Grandma 策略，即“奶奶都会”），并提供免费指标（在 K 线上方/下方画 X 标记）。
- **交易什么**：股指日内。
- **核心方法**：利用指标标记的**微支撑（mSup）/微阻力（mRes）**做两段式入场——X 在 K 线上方 = 微阻力（找卖出机会），X 在下方 = 微支撑（找买入机会）。入场方式是本书第 3.10“信号 K + 入场 K”的精确版：
  1. 标记 X 的那根 K 线是**信号 K 线**；
  2. 找一根收盘破位的同向 K 线作为**触发 K 线**；
  3. **不在触发 K 线收盘时进场，在触发 K 线下方/上方 1 跳处挂止损单等待**——安全入场，让市场来成交；
  4. 止损用信号 K 线高低点，或**资金止损**（账户能承受的金额，如缺口大 K 线中点）。
- **故障安全设计（它的独特点）**：如果入场后被反向困住（触发 K 线上方买入后价格反向），**先别止损**——在信号 K 线位置挂限价单加仓摊平，把均价拉回成本附近，等市场回到原入场点保本离场（“修正交易并称其为哑弹”）。注意：这与本书军规“不浮亏加仓”相抵触——它的前提是微支撑/阻力位极其精确（1 跳级），新手复制不了这种精度，建议只学入场纪律、不学摊平。
- **要警惕的**：依赖免费指标的 X 标记（黑盒逻辑）；“反向利用”（逆势交易）与“破位失败反手”属于进阶玩法，新手先只做顺势版。

### C.9 Rose 八大主题——把 Brooks 概念拆成专题

Rose 除 GRANDMA 外，还公开了八大主题课（与本书各章对应）：

1. **买入区域/卖出区域**：机构挂单进出的位置（对应第 2.4 支撑阻力 + 第 5 章流动性）。
2. **三推的正确画法**：如何避免第四、第五推，怎样入场在趋势起点（对应第 2.8 柱计数/楔形）。
3. **三推情绪线**：三推之后机构在哪止盈（对应第 3 章出场目标）。
4. **孕线（Mother bar）刮头皮**：机构在孕线中如何高抛低吸，怎样避免孕线突破被套（对应第 3.5 内包线）。
5. **失败的失败是波段**（FOFS，Failure of Failure is Swing）：假突破的假突破 = 波段机会（对应第 3.2 假突破 + 第 4 章系统一）。
6. **怎样判断区间突破**：从价格控制看透区间突破方向（对应第 4.5 系统三 + 4.4 第二腿陷阱）。
7. **如何参与旗形回调**：利用大影线实现回调入场（对应第 3.3 pin bar + 系统一）。
8. **错过趋势如何补救**：趋势中途入场的策略（对应第 4.6 微通道等中途入场法）。

**怎么用这份清单**：把它当作本书的“查缺补漏索引”——如果你在某主题上薄弱，直接看对应章节，再用 Rose 的讲解换个角度理解。它证明了一个事实：**所有大 V 的专题，都是本书框架某一块的展开**。
