## A. 术语速查表

### 市场结构

| 术语 | 全称 | 含义 |
| --- | --- | --- |
| 支撑 / 阻力（S/R） | Support / Resistance | 价格反复被挡回的水平区：支撑=下方"地板"（买方聚集），阻力=上方"天花板"（卖方聚集）；突破后角色互换（支撑变阻力、反之亦然）（2.4） |
| 趋势 | Trend | HH/HL（上升）或 LH/LL（下降）的连续结构；"趋势是你的朋友"=顺势入场优于逆势（2.3） |
| 区间 / 盘整 | Range / Consolidation | 价格在支撑与阻力之间横盘、无趋势状态；区间里约 80% 的突破失败（3.11），玩法切换成高抛低吸或等真突破（4.5） |
| 突破 | Breakout | 价格离开区间/结构的关键位并获确认（FT）；真突破顺势、假突破反手（3.2/3.11） |
| 回调 / 回撤 | Pullback | 趋势中的反向小段运动，顺势入场的最佳位置（H2/L2，4.3） |
| HH | Higher High | 更高的高点（上升趋势特征） |
| HL | Higher Low | 更高的低点（上升趋势特征） |
| LH | Lower High | 更低的高点（下降趋势特征） |
| LL | Lower Low | 更低的低点（下降趋势特征） |
| Swing | — | 摆动高/低点，结构的基本单元 |
| BOS | Break of Structure | 结构破坏，趋势同向突破（延续） |
| CHoCH | Change of Character | 性质变化（=结构转换），趋势反向破坏（转势警告） |

### 裸 K 机械化形态（Naked Forex，Alex Nekritin & Walter Peters）

| 术语 | 含义 |
| --- | --- |
| Big Shadow | 大影线；影线显著大于实体的 K 线，代表一次方向尝试被拒绝 |
| Wammies | 两根相邻 K 线形成“缺口”后反转的组合，机械化定义明确 |
| Moolahs | 强趋势后的回调入场形态，有明确识别标准 |
| Kangaroo Tails | 袋鼠尾；极长影线 K 线，影线长度达到前 N 根均值的若干倍，反转信号 |
| The Last Kiss | 最后一次回吻；价格最后一次回测突破位后延续，常是趋势启动点 |

> 这些形态的意义不是“多几个名字”，而是证明 PA 可以做到“无指标但有规则”——每种形态都有明确的识别标准、止损位和止盈规则（详见 B 节“PA 改良流派学习路径”）。可勾选示例：Kangaroo Tails 可要求影线长度 ≥ 最近 N 根 K 线影线均值的 2 倍、收盘远离影线末端；Big Shadow 可要求影线 ≥ 实体的 2 倍。具体参数以原书为准，本书只取“机械化”精神。

### 风险与计量

| 术语 | 含义 |
| --- | --- |
| R | 风险单位，1R=单笔止损金额（2R=两倍止损金额，常用止盈目标） |
| RR | Risk-Reward，风险回报比 |
| ATR | Average True Range，平均真实波幅 |
| Pip | 点，外汇最小报价单位（通常 0.0001） |
| 期望值 | 胜率×平均盈利 − 败率×平均亏损 |
| 凯利公式 | Kelly Criterion；f*=(b×p−q)/b，其中 b=盈亏比（平均盈利÷平均亏损）、p=胜率、q=1−p 败率。算出的 f* 是仓位的“理论上限”不是目标——输入不准+回撤极深，实践用 f/2~f/4（6.7） |

| 夏普比率 | Sharpe Ratio；（收益−无风险利率） ÷ 波动；衡量每单位波动换来的超额收益，简化版看平均收益/回撤（8.9） |
| 过拟合 | Overfitting；参数调太细只拟合历史噪声，样本外即失效；用样本外数据 + 参数敏感性检验（8.2） |
| 一致性规则 | Consistency Rule；部分平台要求单笔盈利不超过总盈利的某比例，防重仓赌一把；考核失败常见原因之一（9.4） |
| 执行率 | 完全符合计划的交易占比 |
| SQN | 系统质量指数，√N × 平均R ÷ R标准差（>2 才算有优势） |
| Z 分数 | 衡量盈利是否显著偏离随机（2-5 为盈利交易者常见区间） |
| PDT | Pattern Day Trader，日内交易者规则；美股账户 <$25,000 时每 5 个交易日最多 3 次日内交易（超限冻结） |

## C. 网络大 V 系统参考

### C.1 先立态度：大 V 系统的真相

看任何大 V 系统前，记住三条：

1. **“80% 胜率”“日赚 1000 刀”是营销话术。** 真实可持续的胜率配合 RR2，长期期望值就已经很好了。宣称超高胜率/暴利的，要么选择性展示，要么在卖课。

3. **免费内容是引流，核心往往在付费。** 公开视频学方法思路可以，别指望免费部分给你完整可盈利系统。

正确的用法：从大 V 那里取材（品种选择、时段、具体 setup 的呈现方式），用本书的框架（验证、仓位、风控）去筛选和落地。不照搬，不迷信。

### C.7 Ali Moin-Afshari——微通道与量化突破（10,000 Trades）

- **是谁**：加拿大交易者，网络工程师转行，师承 Van Tharp 课程 + Al Brooks 体系；把 300+ 个价格行为概念编程量化，公开两个代表作：微通道系统与突破白皮书（其公开材料称信号经 Al Brooks 本人验证；本书未独立核实，按“不背书大 V”原则对待）。
- **交易什么**：E-mini 5 分钟日内。
- **核心方法一（微通道，第 4.6 已融入）**：微通道本质是“连续失衡的载体”——3 根同向 K 线 + 微小缺口定义微通道，基础胜率 70%；10 项强度指标衡量的是“失衡是否完整”，每缺 1 项扣 5%；iStop/aStop 双止损体系；以实际风险 aRisk 的 2 倍为目标；超过 6-7 根 K 线警惕回撤。
- **核心方法二（突破白皮书，第 3.11 已融入）**：白皮书把“突破”拆成可编程事件（突破→FT→第二波→筛选），统计数字是这些事件被量化后的阈值——FT 概率 48%；第一波成立后第二波 > 90%；MIG 97%；四个筛选器（避第 3 信号/避通道 3-4 波段/控时段/控回调深度）把 SQN 从 6.3 提到 8.9。
- **有用的**：“设计致胜”的系统开发理念；把“信号 K 质量”等主观概念量化成 IBS、CX 因子这类可编程指标——这是从“感觉”到“规则”的最佳示范；用 SQN 做优化前后对比（第 8.9）。
- **要警惕的**：微通道本质是刮头皮/快节奏交易，新手执行不了；量化结论基于 E-mini 特定时段，跨品种需重新验证。

### C.8 GRANDMA——“连奶奶都会交易”的故障安全入场（Rose）

- **是谁**：Rose，中文圈价格行为交易者，公开策略 GRANDMA（Grandma 策略，即“奶奶都会”），并提供免费指标（在 K 线上方/下方画 X 标记）。
- **交易什么**：股指日内。
- **核心方法**：利用指标标记的**微支撑（mSup）/微阻力（mRes）**做两段式入场——X 在 K 线上方 = 微阻力（找卖出机会），X 在下方 = 微支撑（找买入机会）。入场方式是本书第 3.10“信号 K + 入场 K”的精确版：
  1. 标记 X 的那根 K 线是**信号 K 线**；
  2. 找一根收盘破位的同向 K 线作为**触发 K 线**；
  3. **不在触发 K 线收盘时进场，在触发 K 线下方/上方 1 跳处挂买入/卖出止损单（触发单）等待**——安全入场，让市场来成交；
  4. 保护性止损用信号 K 线高低点，或**资金止损**（账户能承受的金额，如缺口大 K 线中点）。
- **故障安全设计（它的独特点）**：如果入场后被反向困住（触发 K 线上方买入后价格反向），**先别按保护性止损离场**——在信号 K 线位置挂限价单加仓摊平，把均价拉回成本附近，等市场回到原入场点保本离场（“修正交易并称其为哑弹”）。这里要特别说明：它看起来和本书军规“不浮亏加仓”相抵触，但前提完全不同——Rose 能摊平是因为微支撑/阻力位精确到 1 跳级，普通交易者复制不了这种精度；对大多数读者，军规仍然成立：先学入场纪律，不学摊平。
- **要警惕的**：依赖免费指标的 X 标记（黑盒逻辑）；“反向利用”（逆势交易）与“破位失败反手”属于进阶玩法，新手先只做顺势版。

书有合上的时候，市场没有。第 8 章收口时说过：这套框架不预测涨跌，只负责让盈利在数学上可能（正期望值）、让亏损在可控范围内（仓位+止损）、让执行不变形（流程化+军规）。剩下的部分不在书里，在你身上——每一笔交易前的检查单、每一次复盘里的诚实、每一份日志积累的数据。

如果只带走一页，带走前言的最小可用系统；如果只记住一句，记住：**先验证，再实战**。

*本手册为学习笔记性质，不构成投资建议。所有规则请在模拟账户验证 100+ 笔、确认期望值为正后再实战。*
